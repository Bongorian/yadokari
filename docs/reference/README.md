# Reference data

Canonical data files and protocol references that the code and the
other documents point at. The current specification of the product
itself lives in the [docs index](../README.md) and the source.

- `themes9.json` — the canonical definitions of the 9 colour themes
  (POP 1/2, NEON 1/2, VIVID 1/3, CYBER 2/3, MONOTONE 1; default
  CYBER 2). If this file and any document disagree, this file wins.
- `engine-schema.json` — the machine schema for the factory content
  catalog (see [factory library](../factory-library.md)).
- [USB file transfer (MGF1)](usb-files.md) — the wired file-transfer
  protocol and CLI shared with the Wi-Fi file door.
